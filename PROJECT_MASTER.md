# CarbonAudit / AuditorIA – Master Document

## Product name
CarbonAudit.ai

## Core purpose
Build an AI-assisted technical auditing platform for carbon projects, capable of screening eligibility, assessing feasibility, auditing methodological compliance, supporting validation and verification, and assisting with document and spreadsheet completion.

## Strategic vision
The platform should support multiple carbon standards and methodologies, including but not limited to:
- Verra VCS
- Gold Standard
- Isometric
- Puro.Earth
- CAR

It should support both:
- reduction projects
- removal projects

## Core analysis modes
1. Pre-Feasibility
2. Full Feasibility
3. Validation
4. Verification

## Tools
1. Data Room
2. Document Filler
3. Spreadsheet Filler
4. Methodology Library

## Current state
Current MVP already includes:
- Streamlit interface
- technical chat
- full audit flow
- compliance matrix
- report generation
- multilingual UI
- access control
- usage limits

## Current priority
The current priority is to reorganize the project structure and product architecture before implementing the next major features.

## Product development principles
- build in small steps
- do not try to build everything at once
- keep the app functional while evolving it
- document important product and technical decisions
- separate product, technical, and marketing workstreams
