# Analysis Modes

## 1. Pre-Feasibility
Purpose:
- early screening
- identify whether the project appears potentially eligible
- identify candidate standards and methodologies
- identify immediate blockers and missing documents

Output:
- preliminary eligibility view
- potential methodology fit
- critical gaps
- next steps

## 2. Full Feasibility
Purpose:
- deeper technical and documentary assessment
- evaluate maturity across modules
- identify readiness risks

Output:
- module scores
- maturity and readiness gaps
- recommended workplan

## 3. Validation
Purpose:
- methodology-based compliance audit
- requirement-by-requirement comparison
- project vs methodology analysis

Output:
- compliance matrix
- summary report
- findings
- audit trail

## 4. Verification
Purpose:
- assess readiness for monitoring and verification cycles
- compare monitored evidence against expected requirements

Output:
- verification readiness
- missing evidence
- monitoring weaknesses
- recommended corrective actions
