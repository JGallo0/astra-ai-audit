# Decision — Product Scope

## Decision
The platform will be structured as a multi-mode carbon project copilot with the following core modes:
- Pre-Feasibility
- Full Feasibility
- Validation
- Verification

## Reason
This structure better reflects how carbon projects are actually developed and certified.

## Consequence
The app architecture, data model, and navigation should all be aligned with analysis modes rather than a single audit flow.
